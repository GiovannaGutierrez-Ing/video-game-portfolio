# Video Game Portfolio

A collection of academic and collaborative video game projects developed during my Video Game Engineering studies at the University of Guadalajara.

This portfolio showcases my experience and contributions in game development, project documentation, game design, and collaborative production.

##  Projects

### 1. Beers Shop
**Genre:** Arcade / Casual

A game set in a bar where the player takes the role of a bartender, serving beer mugs to rats that appear throughout the gameplay.

**Focus:** Gameplay concept and collaborative game development.

**Status:** Documentation in progress.



### 2. Beers & Crystals
**Genre:** Top-down Action Roguelike

An action roguelike featuring Barret, a dwarf miner exploring dangerous mines, fighting creatures, and collecting crystals in search of the Primordial Beer.

**Focus:** Game Design Document (GDD) and collaborative game development.

**Status:** Documentation in progress.



### 3. Motor del Cosmos
**Genre:** 3D Educational Simulation

A 3D solar system simulation developed with Unity, exploring planetary motion through a simplified implementation of gravitational principles.

**Focus:** Programming contributions related to planetary masses, research, and educational project development.

**Recognition:** Contributed to a chapter intended for the *Libro Blanco del Desarrollo de Videojuegos 2024–2025* (second edition). Publication pending.

**Status:** Documentation in progress.
