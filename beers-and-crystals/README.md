# Beers & Crystals

**Genre:** Top-Down Action Roguelike  
**Project Type:** Collaborative Academic Video Game Project  
**Platform:** PC  
**Development Context:** University of Guadalajara

## Overview

Beers & Crystals is a top-down action roguelike centered on exploration, fast-paced combat, mining, and absurd humor.

The player takes control of Barret, a stubborn dwarf miner searching for the legendary Primordial Beer. His journey takes him through dangerous underground mines filled with hostile creatures, valuable crystals, and unexpected challenges.

The game combines combat, resource collection, exploration, and run-based progression within a humorous fantasy setting.

## Core Gameplay Concepts

- **Exploration:** Navigate underground environments and discover new areas.
- **Combat:** Fight enemies using melee attacks, firearms, explosives, and improvised weapons.
- **Resource Collection:** Gather crystals by destroying environmental objects.
- **Progression:** Use collected crystals to purchase immediate upgrades.
- **Run-based Gameplay:** Death resets the current run's inventory and progress.

## Game Design

The project explores the following design areas:

- Core gameplay loop and player mechanics.
- Character and enemy design.
- Combat and resource economy.
- World-building and narrative.
- User interface and player feedback.
- Visual and audio direction.
