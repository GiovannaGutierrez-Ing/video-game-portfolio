# Motor del Cosmos – Solar System Simulator

## Project Overview

Motor del Cosmos is an educational 3D Solar System simulator developed in Unity 6 using C#.

The project explores planetary motion through a simplified implementation of Newton's Universal Law of Gravitation, providing an interactive environment to understand gravitational concepts and the behavior of celestial bodies.

## Technologies

- Unity 6
- C#
- Visual Studio
- Unity Physics Engine (PhysX)

## Project Features

- 3D representation of the Solar System.
- Simplified gravitational simulation.
- Planetary motion and orbital behavior.
- Interactive time-scale controls.
- Educational visualization of astronomical concepts.
